# Бесплатный Telegram AI-бот (Groq + GPT-OSS 20B)

Telegram-бот с AI-ответами, контекстом диалога и webhook на Render.

## 1. Создай Telegram-бота

1. Открой [@BotFather](https://t.me/BotFather).
2. Отправь `/newbot` и следуй инструкциям.
3. Сохрани токен в надёжном месте. Не публикуй его.

## 2. Получи бесплатный Groq API key

1. Открой [Groq Console](https://console.groq.com/).
2. Зарегистрируйся / войди и создай API key.
3. Используй бесплатный Developer/Free tier, не переходи на платный Developer tier и не добавляй платёжные данные, если хочешь сохранить проект бесплатным.
4. Выбранная модель: `openai/gpt-oss-20b`. Доступность и лимиты зависят от текущего бесплатного тарифа и аккаунта.

## 3. Загрузить проект в GitHub

1. Распакуй архив.
2. Создай новый репозиторий на [GitHub](https://github.com/).
3. Загрузи в репозиторий все файлы и папки из архива. Не загружай токены или `.env`.

## 4. Развернуть на Render

1. Открой [Render Dashboard](https://dashboard.render.com/).
2. Выбери **New → Blueprint**.
3. Подключи GitHub и выбери репозиторий с `render.yaml`.
4. При настройке добавь:
   - `TELEGRAM_BOT_TOKEN` — токен от BotFather.
   - `GROQ_API_KEY` — ключ из Groq Console.
5. Оставь `GROQ_MODEL` равным `openai/gpt-oss-20b`, тариф сервиса — **Free**.
6. Нажми Deploy.

Приложение автоматически зарегистрирует webhook Telegram при старте. Проверь адрес `https://ИМЯ-СЕРВИСА.onrender.com/health`: ответ должен быть `{"status":"healthy"}`. После этого отправь боту `/start`.

## Команды бота

- `/start` — приветствие
- `/help` — помощь
- `/clear` — очистить историю переписки

## Важно про бесплатный режим

- Groq Free tier имеет ограничения по запросам и токенам; лимиты могут меняться. При достижении лимита бот попросит подождать.
- Не включай платный Developer tier и не добавляй платёжные данные, если не хочешь никаких расходов.
- Render Free усыпляет веб-сервис после 15 минут без входящего трафика; первое сообщение после простоя может отвечаться с задержкой примерно в минуту.
- Render может перезапускать бесплатный сервис. История переписки хранится в оперативной памяти и при перезапуске теряется.
- Не публикуй API-ключи в GitHub и не отправляй их в чат.
